# Mise agent guidance

Mise is a culinary knowledge base and cooking system with an Astro static site.
Read `CLAUDE.md` for culinary philosophy, recipe review criteria and project
conventions, and `README.md` for the current repository map. For recipe work,
follow `docs/RECIPE_STANDARD.md`, `docs/RECIPE_REVIEW_PIPELINE.md` and the latest
checkpoint in `docs/REVIEW_PROGRESS.md`; reconcile their dated instructions.
The coordination guidance below does not replace those culinary standards or
change an active campaign's assignments, integration ownership or release scope.

## Substantial work

Before substantial work, assess expected size and duration, uncertainty, stakes, dependencies and time to the first useful finding. Verify available tools. Favor parallel execution for independent parts when benefits exceed coordination overhead; keep simple or tightly dependent work direct. When a safe, authorized pilot can reduce uncertainty, use it before scaling; otherwise choose an appropriate evidence checkpoint. Reassess after early evidence. Use batch processes and independent review where they improve reliability. Keep one lead accountable for integration, explicit write ownership and checkable completion criteria. Preserve project boundaries and approvals; delegation grants no additional authority. Verify against sources or tests, reconcile disagreements, and report sampled or incomplete coverage honestly. Load adopted coordination guidance when available; otherwise follow this baseline and local instructions, report consequential gaps, and pause only work depending on missing evidence or permission.

This baseline applies to new tasks or an explicitly agreed handoff; it does not
restart or change work already assigned. Existing project instructions and
task-specific constraints remain controlling.

Adopted coordination reference: [central standard](https://github.com/Silton-Strategies/agent/blob/f8863b5aca85bf1920b458a09791611892012d56/practice/core/delegation.md).
This reference is optional; ordinary work does not require access to the private
practice repository. This repository remains independent.
