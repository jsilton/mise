# Image style trials

Four code-drawn approaches to recipe art, tried on Dal Tadka, Beef and Broccoli and Steven's Margaritas:
a_painted.py (painted plate), b_flatlay.py (overhead flat-lay), c_poster.py (bold graphic), d_papercut.py (cut paper).

Run `python3 <file>.py <out-dir>` to write the SVGs. Nothing here is wired into the site yet.
