# Public prose cleanup review

Audited all 605 recipe files and 87 meal files with targeted searches across body text and public frontmatter fields, then read the matched passages and their relevant context. This is a prose audit, not a new culinary review. The reviewer prepared isolated proposals; root subsequently applied the reviewed changes as recorded below.

Prepared 49 exact replacements across 39 files: 44 core replacements and 5 separately marked overlap candidates for the branding pass. Root owns mint-tzatziki; it is deliberately absent.

## Reviewable artifacts

- `replacements.json`: exact old/new strings, file path, observed line, reason and core/overlap group. Apply only if the old string still matches current content.
- `proposed/src/content/`: complete proposed file snapshots for reading; avoid copying these wholesale over concurrent changes.
- `rewrites.md`: human-readable exact changes.

## What belongs in public cooking content

Keep Jordan Silton and Grandmommy attribution, truthful family-recipe labels, the Southern dressing’s herb-forward composition, links that identify the source author, ingredient identity and amount, approximate yields, actionable substitutions, timing, endpoints and storage limits. Keep ordinary cooking tests such as tasting a grain, test-frying falafel and checking a thermometer. “Family-style” describes serving and is not personal-preference commentary. “Household freezer” and home-pan capacity describe equipment limitations, not private biography.

## What belongs in review records

Archive recovery, missing historical brands, why a later rewrite was reversed, deliberate formula adjustments, unperformed kitchen testing, yield-validation questions and source-access limitations belong in `docs/reviews/<recipe>.md` (or the corresponding meal review record). Preserve those records; do not erase uncertainty simply because it is removed from the public page. In particular, Grandmommy’s unidentified historical cornmeal product remains an open review question while the public recipe clearly names the mix required for the written formula.

The buttermilk/yogurt substitution still warns that thickness varies and requires draining. Approximate cornbread/mash yields still say about. The oil and pickle storage restrictions remain explicit. The rewrite does not replace an untested formula with a claim of physical validation.

Redirect and legacy-address maintenance belongs in technical/review records. Public readers need the current dish name and storage instructions. Deleted defensive authenticity statements do not authorize inventing a regional origin; descriptions remain tied to actual composition.
