# Historical automated reports

`legacy-chef-review-report.json` is an April 2026 automated scoring artifact, retained for provenance. Its labels (including “exemplary”) are not evidence of a considered recipe review, reproducibility, safety, or kitchen testing. It has been removed from public site assets. Current review status lives in `docs/recipe-review-register.json`; specific findings live in `docs/reviews/`.

## Moved here on November 10, 2026

`audits/` and `deferred-review-drafts/` used to sit directly under `docs/`. No script, test, page or workflow reads them. Older records that cite `docs/audits/` or `docs/deferred-review-drafts/` mean these folders.
