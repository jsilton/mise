# Basmati Rice: individual editorial review

Date: 2026-09-06. Status: editorial review; no physical kitchen test recorded.

## Findings and corrections

- Kept the original 400 g/720 ml starting ratio but restricted it to unsoaked aged white basmati in a tight 2–3 quart stovetop pan. Removed the universal soaked-rice two-tablespoon deduction and interchangeable cooker/stovetop instructions.
- Tilda's current closed-pan guidance uses a different ratio and shorter rest. This supports method dependence, not validation of our inherited ratio. Physical testing of the specified pot/rice combination remains essential.
- Reconciled six side portions (about 67 g dry rice each), named salt type, and separated optional cumin/whole-spice/plain choices. Removed the unaccounted cardamom alternative for a simpler base specification.
- Added a real hydration check, measured rescue water, and 40-minute total including the ten-minute rest. Removed absolute grain-texture and cultural claims, and added conservative cooling/reheating guidance.
